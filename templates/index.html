Sample File Formats

Bundle ID CSV File Format

Create a CSV file with two columns: Bundle ID and AppAdsURL

Bundle ID,AppAdsURL
com.instagram.android,
com.facebook.katana,https://facebook.com/app-ads.txt
com.twitter.android,
com.spotify.music,https://spotify.com/app-ads.txt
com.netflix.mediaclient,
com.whatsapp,
com.telegram,https://telegram.org/app-ads.txt

✓ Bundle ID is required | ✓ AppAdsURL is optional (can be left blank) | ✓ If AppAdsURL is blank, the app store is looked up to discover it

Domain CSV File Format

Create a CSV file with an identifier column named either Domain or Bundle ID (both work - no need to rename your sheet), and an optional AppAdsURL column. Checks the value directly - no app store lookup involved.

Domain,AppAdsURL
example.com,
chathispano.com,
custom-site.com,https://custom-site.com/special-ads.txt

✓ Domain or Bundle ID column is required (either name works) | ✓ AppAdsURL is optional | ✓ If AppAdsURL is blank, <value>/ads.txt is checked by default | ✓ If AppAdsURL is filled in, it's used exactly as given

Lines to Check Text File Format

Create a text file with one domain/line per line. The app will check if these domains/lines appear in the app-ads.txt file

thejungletechnology.com
google.com
facebook.com
amazon.com
openx.com
pubmatic.com
inmobi.com
freewheel.com
smartyads.com
bidstack.com

✓ One entry per line | ✓ Blank lines are ignored | ✓ Lines are trimmed automatically
